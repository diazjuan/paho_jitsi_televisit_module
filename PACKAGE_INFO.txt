## Quick Start

1. **Extract the package**:
   ```bash
   tar -xzf paho_jitsi_televisit.tar.gz
   # OR
   unzip paho_jitsi_televisit.zip
   ```

2. **Copy to OpenEMR**:
   ```bash
   cp -r paho_jitsi_televisit /path/to/openemr/interface/modules/custom_modules/
   ```

3. **Set permissions**:
   ```bash
   chown -R www-data:www-data /path/to/openemr/interface/modules/custom_modules/paho_jitsi_televisit
   chmod -R 755 /path/to/openemr/interface/modules/custom_modules/paho_jitsi_televisit
   ```

4. **Install via OpenEMR**:
   - Log in as administrator
   - Go to Administration → Modules → Modules Manager
   - Find "PAHO Jitsi Televisit"
   - Click "Install SQL" then "Install" then "Enable"
   - Click "Configure" and set your Jitsi Base URL
