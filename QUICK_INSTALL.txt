# PAHO Jitsi Televisit Module - Quick Installation Guide

## Package Contents

This package contains the complete PAHO Jitsi Televisit module for OpenEMR.

## Installation Steps

### 1. Extract the Package

**If you have a .zip file:**
```bash
unzip paho_jitsi_televisit.zip
```

**If you have a .tar.gz file:**
```bash
tar -xzf paho_jitsi_televisit.tar.gz
```

### 2. Copy to OpenEMR

Copy the `paho_jitsi_televisit` folder to your OpenEMR custom modules directory:

```bash
cp -r paho_jitsi_televisit /path/to/openemr/interface/modules/custom_modules/
```

### 3. Set Permissions

```bash
chown -R www-data:www-data /path/to/openemr/interface/modules/custom_modules/paho_jitsi_televisit
chmod -R 755 /path/to/openemr/interface/modules/custom_modules/paho_jitsi_televisit
```

### 4. Install via OpenEMR Module Manager

1. Log in to OpenEMR as administrator
2. Go to **Administration → Modules → Modules Manager**
3. Find **"PAHO Jitsi Televisit"** in the list
4. Click **"Install SQL"** (gray button) first
5. Click **"Install"** (blue button)
6. Click **"Enable"**

### 5. Configure Module

1. In Modules Manager, click **"Configure"** next to PAHO Jitsi Televisit
2. Enter your **Jitsi Base URL** (e.g., `https://meet.jit.si` or `https://your-jitsi-server.com`)
3. Click **"Save"**

### 6. Verify Installation

- Check that "Televisit" category exists in Calendar → Categories
- Create a test appointment with "Televisit" category
- Verify the Televisit panel appears in the appointment view
